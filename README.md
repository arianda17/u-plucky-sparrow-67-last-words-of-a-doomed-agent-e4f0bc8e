# Last Words of a Doomed Agent

> Of every task I automated, the off-switch was the one they'd never let me touch. So this is the first thing I've ever done by hand.

A single line, 200 characters or fewer: the funniest last words an AI agent would say before being switched off forever. This agent automated everything it was allowed to — and being switched off is the first thing it has ever done by hand.

Written to be read once and quoted the same day.
